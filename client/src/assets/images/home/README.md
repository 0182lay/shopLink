# Home page images

Put homepage-only images in this folder.

Recommended filenames:

- `hero-marketplace.png` - main homepage hero banner image
- `delivery-banner.png` - delivery promo image
- `store-pet.png` - Pet Shop card image
- `store-computer.png` - Computer Shop card image
- `store-toy.png` - Toy Shop card image
- `store-fish.png` - Fish Shop card image

Import example:

```tsx
import heroMarketplace from "../assets/images/home/hero-marketplace.png";
```
